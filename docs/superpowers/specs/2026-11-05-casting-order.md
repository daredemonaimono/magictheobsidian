# 呪文を唱える手順と、マナを払うタイミング (ルール資料)

日付: 2026-11-05 / 出どころ: じゅまが貼ったもの(そのまま記録)。エンジン (`castCore` in `src/battle/engine.ts`) と、対戦の画面は、これに沿う。

## 手順

呪文を唱える際は、以下のステップを順番に進める。追加コストが関係するのは主に ⑤ と ⑦。

1. ① 宣言と移動: カードを公開し、スタックに置く。
2. ② モードの選択: モード、追加コスト(キッカーやバイバックなど)を支払うかどうか、代替コストで唱えるかどうかを決める。
3. ③ 対象の指定: 呪文の対象を選ぶ。
4. ④ 配分: ダメージやカウンターなどの割り振りを決める。
5. ⑤ 総コストの決定: マナ・コスト(または代替コスト)に、選んだ追加コスト(生け贄、手札を捨てる、追加マナなど)をすべて足し算し、軽減効果を引いて、最終的に支払う「総コスト」を確定させる。
6. ⑥ マナ能力の起動: 必要であれば、マナを生み出す土地やクリーチャーの能力をこのタイミングで起動する。
7. ⑦ コストの支払い: 確定した総コスト(マナ、ライフ、生け贄など)を、任意の順番で「すべて同時に」支払う。

## いまの実装との対応

- ②: `cast.kicked` / `cast.teamwork` (追加コストを払うか)、`cast.modes` (モード)。画面は、**追加コストを払えるだけのマナがあるとき**、唱える前に「払って唱える / 払わずに唱える」を選ばせる (`BattleController.kickChoices`、0.82.0 から)。この選択は、対象を選ぶ(③)より前。
- ③: `targets`。④(割り振り): 戦闘ダメージだけ (`assignDamage`)。呪文の割り振りは、まだ。
- ⑤: `castCore` が、マナコスト(コスト軽減を引く)+選んだ追加コストを、1つの `CostSpec` に足す。
- ⑥: 人の画面は、**カードを選ぶ → (追加コスト・対象を聞く) → 足りないマナを、自動でタップして払う** (0.82.0 から。公式の順番)。カードを選んだ時点で、土地・マナ能力のマナを全部出せるとして払えなければ、「マナが足りません」と出て、何も起きない (`BattleController.whyNot`)。**手で土地をタップする操作は、なくした** (0.84.0 から。マナ能力は、画面で光らず、手の一覧にも出ない。エンジンの `activate` は、テスト・AI のために残す)。相手 (雑魚 CPU・Claude) も、唱えるとき、必要なぶんだけ自分でタップする (`tapFor` / `cpuDo`)。タップする土地は、種類の違うマナ源から選べる余地があるとき、選ばせる (`payChoice` / 画面の `askMana`)。「自動で選ぶ」のときの順番は、並んでいる順 (shortcut: 色は見ない。多色のデッキでは、要らない色を出すことがある)
- ⑦: `payCost` が、マナ・タップ・生け贄などを、まとめて払う (払えなければ、`RuleError` で、状態は変えない)。
- (エンジンの) 使い道のないマナのタップは、拒否する (`uselessMana`)。画面では、手でタップしないので、使われない。
- 手札のカード・マナを払う能力 (装備など) が光る条件は、土地・マナ能力のマナを全部出せるとして、使えること (`boardModel` の `playable`)。出せるマナの合計が足りなければ、光らない。

## まだ無いもの

- 呪文の割り振り(④)。
