# 盤面のカードの見た目 (オリジナルフレーム) — 作業の記録と引き継ぎ

セッションが切り替わっても、続きから作業できるようにするための記録。更新したら、日付を書き足す (最終更新: 2026-11-10。Arena 見本に合わせた再現を、未確認で反映)。

## 方針 (じゅまが決めた)

- 目標: MTG Arena の盤面に、見た目を近づける。**CSS で、枠・名前の帯・P/T 板を描く** (カード画像を切り抜いて新しい枠を描く方式は、廃止)。
- 絵は、Scryfall の `art_crop` (絵の部分だけの画像) を使う。名前・色・P/T は、カードのデータから。
- 設定「盤面のカードの見た目」は、`frame` (オリジナルフレーム。既定) と `full` (カード全体) の 2 つ。昔の値 `art` は、`frame` として読む。
- 進め方: じゅまが、Arena の画像と、Obsidian の画像を並べて見せる → 違いを直す、を繰り返す。**じゅまは、細かい数値 (0.2px 単位) で指示する**ので、そのとおりに動かす。
- 見た目の確認は、じゅまが Obsidian で行う。**AI は、実際の Obsidian では見ていない** (CSS の崩れは、ブラウザで簡易のモックを作って確かめたことが1回だけある)。

## 決まっている細かいこと

- 2026-11-10 に、じゅまが Arena の黒のクリーチャー (「無慈悲な監査官」) の画像を見せて「できるだけ再現」と指示。**くびれは廃止**し、角の小さい長方形・横長 (1.2:1) に変更。
- 名前の帯: 明るい灰色・細い暗い縁・文字は左寄せ。右が左より少し長く空く。絵の窓は、ほぼ枠いっぱい。左右の余白に、色ごとの模様 (黒は銀のまだら)。下に、暗い帯を残す。
- 絵の下の板 (バッジ) は無い。**左下の能力アイコンも、不要** (じゅまの指示)。
- P/T 板: 右下の角に収まる、大きな銀色の面取り板 (見本どおり)。以前は「ツルツル」を避けて光沢なしだったが、見本に合わせて面取りを付けた。見え方が気に入らなければ、控えめに戻す。
- 色ごとの模様は、絵の窓の左右に、少しだけ見える。黒は、毒々しい泡。
- 配置: 土地は左から、土地以外は同じ列の右に。土地は、クリーチャーより小さめ。山札は左下、墓地はその右。相手は、右上に、墓地が右端、山札がその左。見下ろす角度は 14 度。
- フォント: 英数字は Philosopher Bold (`styles.css` の先頭に、base64 で埋め込み。ライセンスは `THIRD_PARTY.md`)。日本語は、ヒラギノ明朝 / 游明朝。通信でフォントを読む方式は、ラグが出るのでやめた。

## 落とし穴 (起きたこと)

- CSS のコメントを閉じ忘れると、次の規則が、まとめて飲み込まれる (一度、枠の絵が飛び出す不具合になった)。CSS を足したら、`/*` と `*/` の数が合うか確かめる。
- `sed` と python を `&&` でつなぐと、前が失敗したときに python が動かない。続けて書かない。
- カードの `overflow: hidden` は、P/T 板のはみ出しを切る。枠を描いたカードだけ `:has(> .mtg-bt-fnm)` で `visible` にしている。

## 台座・アバター・スリーブ (2026-11-10、0.159.0)

- 台座: `src/battle/pedestalSvg.ts`。標準は、自作の SVG (鋼の台・銅の輪・反った金と灰の帯)。ダッシュボードの「台座の飾り」に、画像 (輪の穴が透明で、穴の中心が画像の中心。SVG・PNG) をアップロードすると、それに差し替わる (`Settings.avatars.pedestal`)。じゅまの `pedestal.svg` (画像を VTracer で変換したもの) は、権利の理由で、公開物に入れず、`avatars/pedestal-arena.svg` として、手元だけに置く。three.js は、使わない (一度試し、`main.js` が約 2 倍になるので、やめた)。
- 大きさ: `--D` = 台座の輪の直径 (自分 66px / 相手 55px × `--s0`)。点数板は、飾りの手前の帯の下。手札は、台座より手前 (`z-index: 9`)、下の 3 割は画面の外。
- 光: ターンのプレイヤーの絵の輪郭だけ (`.mtg-bt-av-aura`、`opacity` だけの animation)。光線は、やめた。
- アバター・スリーブ・台座の飾り: `Settings.avatars` (cpu / player / sleeve / pedestal)。画像は `avatars/` (git の管理外。`cpu-` `player-` `sleeve-` `pedestal-` で始まる名前のファイルを、手で置けば、起動時に一覧へ足される)。スリーブの標準は、CSS で描いた裏面 (`--back-css`)。Scryfall の裏面画像は、もう読まない。

## 部品と色の変数 (2026-11-10)

赤のクリーチャーで作った部品が、全クリーチャーの標準。部品ごとに、色の変数が 1 つ。`styles.css` 末尾の「部品の色の決め方」に、すべてある。

| 部品 | 変数 | 色ごとの値 (X = W U B R G M C) |
|---|---|---|
| 枠の面 | `--body` | (全色 `#272B2B`) |
| 名前の帯 | `--plate` | `--plate-X` |
| P/T 板 | `--ptc` | `--pt-X` |
| 立体筋 (帯と絵の窓を囲う線) | `--line` | `--line-X` (明るい側・暗い側は、ここから作る) |
| 模様 (左 / 右) | `--pat-l` / `--pat-r` | `--pat-X` (背景の指定そのもの。地の色を含む) |

- 1 色のカード (`.f-R` など): 全部品が同じ色の値を指す。
- 多色のカード: 部品ごとに、別の色の値を指せる。例: `.f-RU { --plate: var(--plate-R); --pat-l: var(--pat-R); --pat-r: var(--pat-U); --line: var(--line-M); }`。いまの `frameClass` (`src/battle/frame.ts`) は、多色を `f-M` 1 つにまとめているだけ。色の組み合わせごとのクラスを出すのは、これから。
- **Arena の見本どおりなのは、赤・黒・青 (2026-11-10)。白・緑・多色 (金)・無色の値は、実物のカードの傾向からの仮**。見本が来たら、`--plate-X` `--pt-X` `--line-X` `--pat-X` を置き換える。
- 形 (帯・窓・筋・P/T 板の大きさと位置) は、色に関係なく共通。変えるときは、`FRAME_LINE` (`src/battle/layout.ts`) も直す。

## 土地 (2026-11-10)

- **新しい枠の土地**: クリーチャーの部品をそのまま流用して、P/T 板を外しただけ (土地専用の色は無い)。色は、土地タイプの色 (`f-R` など) のクリーチャーと同じ。色なしの土地は、無色 (`f-C`) のクリーチャーと同じ。
- **枠なしの古い版の土地** (`f-old`): 黒い縁 → 灰色の大理石の縁 → 絵 (細い明るい線)。名前は左上に小さく。帯・立体筋・模様の代わりに、`.f-old` の規則で描く (`styles.css` 末尾)。
- 古い版かどうかは、カードのノートの `frame` (Scryfall の枠の版) が 1993 / 1997 / 2003 のとき (`src/battle/frame.ts`)。**`frame` は、新しく取ったノートにだけ付く**。既存のノートは、カードの情報を取り直すまで、新しい枠のまま。2003 を古い扱いにするのは仮 (Arena の見本の版が分からない)。
- 土地以外の古い版は、まだ作っていない (ふつうの枠のまま)。

## 山札・墓地の束と、使い込んだ見た目 (2026-11-10)

- **束のばらつき (全フォーマット)**: 層ごとに、少しずらして傾ける (`pileScatter`、`src/battle/layout.ts`)。種は山札・墓地ごとに決まっていて、描き直してもちらつかない。一番上のカードは、控えめに (6 割)。
- **Vintage / Legacy (`.is-worn`)**: 山札・墓地・相手の手札の見た目に、色あせと暗さ (`filter`) をかける。標準の裏面 (CSS) にも、アップロードしたスリーブにもかかる。昔は、使い込んだ旧裏面の画像 (`old-back.png`) を埋め込んでいたが、権利の理由で、公開物から外した (じゅまの手元では、`avatars/sleeve-old.png` として、スリーブに選べる)。
- 手札・盤面のカードは、使い込んだ見た目にしていない (山札と墓地だけ)。
