# Magic the Obsidian

Obsidian を Magic: The Gathering のデッキ構築ツールにするプラグインです。カードは Scryfall から取得してノート(md)になり、デッキ・コレクションもノートで保存されます。

## BRAT でのインストール

1. Obsidian に BRAT プラグインを入れる。
2. BRAT の「Add Beta plugin」に `daredemonaimono/magictheobsidian` を入力する。
3. 設定の Community plugins で「Magic the Obsidian」を有効にする。

## 画面

### ダッシュボード

- コマンド「Open dashboard」か、左のリボンのアイコンで開く。新しいタブ(空のタブ)もダッシュボードになる(設定でオフ可)。
- 「コレクション」「デッキ」「カード」の3つのボタンから、各画面を開く。

### デッキ一覧(ダッシュボード → デッキ)

- All / お気に入りのタブ、名前の検索、使えるフォーマットでの絞り込み(デッキ内の全カードが使えるフォーマット。コマンダーがいるデッキは Commander のみ)。
- 「＋ 新しいデッキ」。窓で名前・フォーマットを選び、Moxfield のテキストを貼ると取り込んで作る(空なら空のデッキ)。
- カードにホバーすると、🗑(デッキのノートごと削除。確認あり。Obsidian の「削除したファイルの行き先」に従う)、♡(お気に入り、`favorite: true`)、🖼(サムネイル、`thumbnail:`)。サムネイルは、デッキで使っているカードアート(デッキで選んだ版)から選ぶ。

### デッキ画面

- コマンド「Create deck」で、デッキ名とフォーマットを選んで作る。`Decks/` にノートができ、専用の画面が開く。既存のデッキのノートは、コマンド「Open current deck in deck view」で画面にできる。
- 上にヘッダー(Moxfield 風)がある。ヘッダー画像(デッキのカードアート。デッキ一覧のサムネイルと同じもので、frontmatter の `thumbnail:`。デッキ一覧で変えると、ヘッダーにも反映される)、デッキ名、フォーマット(選んで変更。いまのデッキが使えるかを ○/×/？ で表示)、更新日時、説明文(`description:`)。フォーマットは選んで、説明文はクリックして編集する。ヘッダー画像は、デッキ一覧の🖼で設定する。下のバーに、メイン/サイドの枚数、デッキの合計価格(コレクションの通貨・価格を使う)、資産(コレクション)に無いカードの差額(同じカードの所持枚数で数える。版は問わない。基本土地は数えない)、タイプ別の枚数が出る。
- カードはタイプ別の見出しに重ねて並ぶ。見出しの並びは全フォーマット共通で、「Commander / Planeswalker / Creature」「Sorcery / Instant」「Artifact / Enchantment / Battle」「Land」の列。ホバーすると、左に拡大画像と効果テキストが出る。
- 重ねたカードにホバーすると、🖼(イラスト=収録セットの選択。選んだ版は `4 [[Lightning Bolt]] (m11 149)` のようにノートに保存)が出る。枚数の増減は、右サイドバーの一覧で行う。裏面の画像があるカード(変身・表裏の両面カード)には ↩︎ も出て、押すと裏面の画像になる(左のプレビューも合わせる)。裏面の画像は、表と同じく取得したときにカードのノートに書く(`![back](…)`。ノートの `layout:` も一緒に付く)。名前が `A // B` で `layout:` の無い古いノートは、デッキ画面の「情報取得」で取り直すと付く。冒険・準備などは、1枚の画像に裏面も載っているので、裏面の画像は書かず、↩︎ も出ない。コレクション画面とカード一覧にも、同じ ↩︎ がある。
- メイン/サイドのタブを押すと、サイドバーが畳まれていれば開く。タブの右の「情報取得」で、トークンを含むデッキ内の全カードの情報を Scryfall から取る(手動)。設定言語のテキスト(`## Text (ja)` など)が無いカード、パワー・タフネス(`power:`/`toughness:`)やキーワード(`keywords:`)が無いクリーチャーは取り直して補い(あるものは触らない)、リーガル情報が無いカードを補い、価格も取り直す。フォーマットはヘッダーで変えられる(統率戦とそれ以外のあいだは不可)。
- トークン(タイプが Token のカード)は、メイン/サイドとは別枠の `## Token` 欄に入り、Land の右の「Token」見出しに並ぶ。フォーマットのルール(使用可否・枚数)と、枚数・価格・○/×の数には入らない。
- ノートの末尾に「メモ」欄ができる(AI の相手が読む、デッキのメモ。下の「デッキのメモ」を参照)。自由に書き換えてよく、画面の操作では消えない。
- デッキのノートはカードへのリンクなので、グラフビューでカードの採用率が見える。

### サイドバーのカード一覧(デッキ画面用)

- デッキ画面を開くと、右サイドバーにカード一覧のタブが置かれ、サイドバーが開いて一覧が前に出る(サイドバーを閉じていても出る)。デッキ画面が全部閉じるとアイコンごと消え、一覧が見えていたならサイドバーも畳む。開いているデッキ(タブを切り替えたデッキ)に追従する。デッキ画面以外のタブに切り替えるとサイドバーは畳まれ、デッキ画面に戻ると開き直す。
- デッキ名の横のボタン(メイン/サイド。統率戦のメインはコマンダー込み)で切り替える。デッキ画面のタブも同じに切り替わり、検索から追加するカードの行き先もその欄になる。
- 普段は、いま選んだ欄に入っているカード(枚数つき)を並べる。クリックで+1、Shift+クリックで−1(そのカードがいる欄の枚数)。そのフォーマットで使えないカードは赤く先頭に出る。
- 「＋ 新しく追加」で条件(名前・効果・タイプ・色・デッキ内のカードも含めるか・トークンも含めるか。タイプに「トークン」もある)を入れて検索すると結果に切り替わり、クリックで追加、Shift+クリックで1枚削除。「← デッキ内に戻る」で戻る。
- 並びは、デッキ画面の見出しと同じ順で、同じ見出しの中はコスト順。コストと色はマナシンボルのアイコン(画像は Scryfall から読み込む)。イラストを薄く出せる(設定でオフ可)。
- 設定の「カード一覧をサイドバーに出す」をオフにすると、デッキ画面の中の検索欄に戻る。

### コレクション

- コマンド「Open collection」か、ダッシュボードの「コレクション」。「Add cards」で検索して追加する。
- グリッド/リスト表示。セット・色・名前で絞り込み。版ごとの価格と合計。通貨は設定で選ぶ(既定は USD)。Scryfall の USD(TCGplayer の価格)が無いカードは、EUR(Cardmarket の価格)を、為替レート(Frankfurter)で設定の通貨に換算して出す。レートは価格の更新と、通貨を変えたときに取る。価格は「価格を更新」ボタンかコマンド「Update collection prices」で手動更新する(自動では取得しない)。
- 行ごとに状態(NM/LP/MP/HP/DMG)と foil を記録する。グリッド表示では foil のカードに虹色の光(動かない)を重ねる。ホバーで1枚だけ変更できる。

### カード一覧(ダッシュボード → カード)

- `Cards/` のカードを、フィルター付きで見る。クリックでカードのノートが開く。
- ホバーして「↻」で、そのカードだけ Scryfall から取り直す。frontmatter は取り直した項目だけ上書きし、本文は作り直す(本文に書いたメモは消える)。
- 効果テキストの言語が日本語のときは「Wiki」で、MTG Wiki のそのカードのページをブラウザで開く。

## 対戦(作成中)

- **土地は、手でタップしない**(0.84.0 から): マナは、カードや能力を使うとき、足りないぶんの土地・マナ能力を、自動でタップして払う。土地(やマナ能力)をクリックしても、何も起きない(光らない)。どの土地を使うか選びたいときは、下の「払う土地の選択」で選ぶ。

- **スタックのカード**: 呪文や能力がスタックに積まれると、盤面の左(相手の墓地の下あたり)に、一番上(次に解決されるもの)のカードの画像が大きく出る(効果を読んで、応答できるように)。自分は青枠、相手は赤枠。能力のときは、画像の下に、どの能力かが出る(プレインズウォーカーなら「+1: 〜」「−2: 〜」、誘発型なら「誘発: 〜」)。画像の下には、効果テキストも出る(カードのノートの本文。プレインズウォーカーの能力は、使った能力の1行だけ。「以下から選ぶ」は、見出しと、選んだモードだけ。それ以外の能力は、カードの全文)。下に積まれたものは、1行ずつ。

- **墓地の中身**: 墓地(自分・相手)にカーソルを合わせると、サイドバーに、中のカードの一覧(新しく入ったものが上)が出る。一覧のカードにカーソルを合わせると、その下に、画像と効果が出る。

- **カードを選ぶと、足りないマナは自動で払う**(公式の順番): カードをダブルクリック → 追加コスト・対象を聞く → 足りないぶんの土地を自動でタップして唱える。足りないマナを払う土地に**選べる余地があるとき**(種類の違う土地があり、全部は要らないとき)は、どの土地をタップするか選ぶ質問が出る(払えるだけ選ぶと「確定」。「自動で選ぶ」で並んでいる順。同じ種類の土地だけのときは聞かない)。土地(やマナ能力)のマナを全部出しても足りないときは、カードを選んだ時点で「マナが足りません」と出て、カードは光らない。使えない理由(攻撃・ブロックの不正など)は、画面の下にも出る。
- **追加コスト(キッカーなど)**: 追加コストを払えるだけのマナがあるとき、カードを使う(ダブルクリック)と、先に「払って唱える / 払わずに唱える」を聞く。そのあと、対象を選ぶ。マナが足りなければ、聞かずに、払わずに唱える。唱える手順は `docs/superpowers/specs/2026-11-05-casting-order.md`。

### 対戦の履歴(段階8a)

- 対戦が終わったとき(勝敗が付いたとき)、または途中でやめたとき(画面を閉じる・新しい対戦を始める)、`Battles/<日時> <自分のデッキ> vs <相手のデッキ>.md` に、1試合を1つのノートとして保存する(設定「対戦の履歴を保存する」でオフにできる)。
- ノートの上のほうに、勝敗・ターン数・相手の種類(雑魚 CPU / Claude とモデル)・Claude が使ったトークン数・乱数の種。続いて、ログ(読める文章)。最後に、**リプレイ用の記録**(JSON。書き換えない)。
- 記録は、画面・CPU・Claude が呼んだエンジンの入口(カードを使う・攻撃・ブロック・「次へ」など)の並び。同じ種・同じデッキから、この並びを呼び直すと、同じ局面になる(テストで確かめてある)。
- **リプレイ**: コマンド「Battle: replay」で、保存した対戦の一覧(新しい順)が出る。選んで「再生」を押すと、対戦の画面が開いて、**自動再生**する(0.7秒ごとに1手)。**スペース**で再生・停止、**→ / ← キー**で、次・前(自動再生は止まる)。画面上のバーも「次へ」ボタンも出ない(キーだけで操作する)。再生では、記録した操作を呼び直すだけで、**Claude の API は呼ばない**(費用は掛からない)。操作は受けない。デッキ・ルールのノートが、記録したときから変わっていると、局面が食い違うことがある。
- AI が履歴から学んで、デッキごとのメモを作る機能は、あと。

- **忠誠度でマナを出す能力(Chandra の +1 など)**: ルール上、マナ能力ではない(スタックを使い、1ターンに1回)ので、自動では使わない。先に、プレインズウォーカーをダブルクリックして、能力一覧(「+1: マナを加える」)から使う → 「解決する」。入った制限つきのマナは、画面のマナの表示に「◇1 (クリーチャー以外)」と出る。そのあと、使える呪文を唱える(制限に合わない呪文には使えない)。呪文を選んで「マナが足りません」と出たときは、使えば払えそうな、この種の能力があれば、「Chandra の +1 を先に使うと、払えるかもしれません」と案内が付く。

- **スペースキー**: 対戦中は、スペースキーで、右下のボタン(「次へ」「解決する」「攻撃する」「ブロックする」「確定」「ダメージを割り振る」)を押せる。質問の画面(捨てる・選ぶ・マリガンなど)が出ている間や、文字を入れている間は、効かない。押しっぱなしでは、連続で進まない。

### 相手の手札を見たとき

- 「手札を見る」効果(ノード `lookHand`)で相手の手札を見ると、相手の手札のカードが、**表向きで、盤面の上に並んで**出る。**クリックか Esc で閉じる**(ゆっくり見られる。放っておいても、30秒で消える)。設定「対戦の演出」でオフにできる。見る効果を使うカードの選ぶ画面(「1枚選んで、捨てさせる」)も、そのカードの一覧が出る。
- 相手の手札は、ふだんは、盤面に出さない(見えない情報)。ログには、「相手の手札を見た: カード名、…」と残る。

### 対戦のサイドバー

- 対戦の画面を開くと、**右のサイドバーが開いて**、上にカードのプレビュー(カーソルを合わせたカード・墓地の一覧)、下に対戦のログが出る(アイコンは、剣)。デッキ画面のカード一覧と同じ動き: 対戦の画面を閉じると、サイドバーも閉じる。他のタブに切り替えると畳まれ、対戦の画面に戻ると開き直す(手で畳んだときは、開き直さない)。
- 上の「カード」と下の「ログ」は、枠線と見出しで分かれている。ログは、ターンの始まりの行の上に罫線が入り、カード名は太字で出る。
- 上の「カード」と下の「ログ」は、枠線と見出しで分かれている。ログは、ターンの始まりの行の上に罫線が入り、カード名は太字で出る。
- 設定の「サイドバーを使う」をオフにすると、プレビューとログは、これまで通り、対戦の画面の中(右端)に出る。

### デッキのメモ(AI の相手が読む)

- デッキ画面の**ヘッダーにカーソルを合わせると、右上に、メモのアイコン**が出る。押すと、そのデッキの「AI へのメモ」を、自由に書ける(マリガンの基準・立ち回り・コンボなど)。デッキのノートの `## メモ` の欄に保存される(ノートに直接書いてもよい。昔の `## 動き方` の欄は、作らず、読まない)。
- 対戦で、**AI の相手がそのデッキを使うとき**、メモを、毎回の判断の指示に足して渡す。あなたのデッキのメモは、渡さない。メモに書いていないことは、AI が自分で判断する。
- **AI の相手のマリガンは、AI が決める**(メモに基準があれば、それに沿う。無ければ、自己判断)。返事が使えない・通信の失敗のときは、そこから先を、雑魚 CPU の決まりで済ませる。マリガンの結果は、履歴に残り、リプレイで、同じ手札になる。
- **メモの下書き**: コマンド「Battle: draft deck memo」で、デッキを選ぶと、そのデッキが出てくる対戦の履歴(`Battles/`)が出る(新しい5試合に、最初から印が付く。変えられる)。「下書きを作る」を押すと、選んだ AI に、勝敗・ターン数・ログの要点(そのデッキを AI が使った試合は、AI が返した理由も)と、今のメモを送って、下書きが返る。**読んで、直して、「メモに追記」か「メモを置き換える」を押すまで、何も保存されない**。履歴の内容が、選んだ AI の会社に送られ、費用が掛かる(送る前に、試合数と字数が出る)。AI が自分でメモを書き換えることはない。
- メモの長さは、1000 字くらいまでが目安(長いと、毎回の費用が増える)。「〜のときは、〜する」と、短い文で書くと、守られやすい。

### 対戦の相手の AI(Claude・OpenAI・Gemini)

- 設定の「対戦の相手」は、切り替えボタン(トグル式)で選ぶ: **雑魚 CPU / AI / 何もしない**。「AI」を選ぶと、その下に、「AI の種類」の切り替えボタン(**Claude / OpenAI / Gemini**)と、選んだ種類の設定が出る。
  - **Claude**: モデル(Haiku・Sonnet・Opus・Fable)を選ぶ。API キーは、下の「AI(ノードの組み立て)」のキーを使う。
  - **OpenAI**: API キー・モデル名・URL。**URL を変えると、同じ形の互換 API**(自分のパソコンで動かす Ollama は `http://localhost:11434/v1`、LM Studio は `http://localhost:1234/v1`)にも使える。URL を変えたときは、キーが無くてもよい(無料で試せる。ただし、小さいモデルは判断が弱い)。
  - **Gemini**: API キー・モデル名。
  - キーは、Obsidian のキーチェーンに保存される(設定のファイルには、保存先の名前だけが残る)。モデル名は、各社の最新のものを、自分で入れる(初期値は、仮のもの)。
- どの AI でも、盤面と選択肢を文章にして渡し、JSON の返事を読み取るのは同じ。使えない返事の聞き直し・失敗したときの雑魚 CPU への切り替え・トークン数のログ・履歴の保存も、同じ。
- 盤面の情報が、選んだ会社のサーバー(互換 API なら、指定した URL の先)に送られる。

### 対戦の画面(段階7: Claude の相手)

- 設定「対戦の相手」を「Claude の AI」にすると、相手が、判断が要る場面で、盤面と選べる行動を API(Anthropic)に渡して、返事のとおりに動く。**判断のたびに、有料の API を呼ぶ**(設定の「Claude の相手のモデル」で、Haiku / Sonnet / Opus / Fable を選べる。API キーは、AI の欄の設定を使う)。
- Claude が決めるのは、自分のメインフェイズの行動(土地・呪文・能力)、攻撃クリーチャー、ブロック、そして応答(あなたの呪文・戦闘のあいだの、瞬速の呪文など)。選べる行動が「何もしない」だけの場面は、API を呼ばずに、パスする。あなたのターンは、スタックに何かあるか、戦闘中のときだけ、応答を聞く。
- 相手が考えている間は、画面上に「相手 (Claude) が考えている…」と出て、操作は受けない。Claude が返した短い理由は、ログには出さない(ログは、起きたことだけ)。理由は、履歴のノートの記録(JSON)の中に、行動の番号つきで残る(あとで学ぶのに使う)。
- 返事が使えなかった(JSON として読めない・できない行動)ときは、理由を添えて1回聞き直す。それでもだめなら、**その判断だけ**雑魚 CPU の決まりで動き、次はまた Claude。API そのものが使えない(キー未設定・通信のエラー・レート制限)ときは、ログに理由を出して、**以降は雑魚 CPU の決まりで動く**(試合は止まらない)。
- 判断のたびに、使ったトークン数(入力・出力・この対戦の合計)が、ログに残る。
- 限界: マリガンは、雑魚 CPU の決まり。AI は、1ターンに数回、API を呼ぶ(遅い・高い)。カードの効果テキストは渡さず、カード名・タイプ・マナ総量・パワー/タフネス・キーワードだけを渡す(Claude が知っているカードの内容に頼る)。

### 対戦の画面(段階6a: 攻撃とブロック)

- **自分の攻撃**: 戦闘ステップの「攻撃クリーチャー指定」で、攻撃できるクリーチャー(青い枠)が光る。クリックで選ぶ(もう一度で解除)。選んでいる間は、右下の「次へ」ボタンが「攻撃する (N 体)」になり、押すと攻撃する。全部の選びをやめると、「次へ」に戻り、押すと攻撃しないで進む(上の帯は出さない)。攻撃先は、相手のプレイヤー。
- **ブロック**: 相手が攻撃してきたら、「ブロック」の段階で、ブロックする自分のクリーチャーをクリック → ブロック先の攻撃クリーチャー(黄色の破線)をクリック。割り当てたものは「→ 相手の名前」と出る(もう一度クリックで解除)。選んでいる間は、右下の「次へ」ボタンが「ブロックする (N 体)」になり、押すとブロックする。全部の選びをやめると、「次へ」に戻り、押すとブロックしない(上の帯は出さない)。ブロックできる組み合わせが1つも無いとき(ブロッカーがいない・飛行に飛行も到達もいない・威嚇に1体しかいない)は、選択を出さず、何もできないので、時間ゲージが進む。飛行・威嚇などの決まりに合わないブロックは、理由がログに出て、変わらない。
- **相手(雑魚 CPU)の攻撃**: 倒されないクリーチャーだけで攻撃する(あなたのライフが致死なら、全員)。**ブロック**: 倒せて生き残るブロッカー → 生き残れるブロッカーの順。攻撃を通すと致死なら、チャンプ・ブロック。攻撃先は、あなたのプレイヤーだけ(プレインズウォーカーは狙わない)。
- ダメージは、カードの上に数字で出る(ターン終了で消える)。自分の攻撃クリーチャーが2体以上にブロックされたら、ダメージの割り振りを選べる。相手のブロッカーのカードの上に「ダメージ N (致死 M)」と出る。カードを**クリックで +1**(ほかのブロッカーから1つ取る)、**Shift+クリックか右クリックで −1**、**ダブルクリックで、そのブロッカーに致死ダメージを先に**割り振る。右下の「ダメージを割り振る」(初期値は宣言の順に致死ダメージ。変えなければ、押すだけ)で確定する。トランプルは、自分の攻撃クリーチャーの上に「相手へ N」(残り)が出る。ダメージを受けたクリーチャー・ライフが変わったプレイヤーには、数字が大きく出て消える演出がある(設定「対戦の演出」でオフにできる。倒れて消えたクリーチャーには出ない)。

### 対戦の画面(段階5: 雑魚 CPU)

- 相手は、機械的な決まりで動く。**マリガン**: 土地が3枚以上で、コストの低い呪文(マナ総量2以下)があればキープ。そうでなければマリガン(2回目からは土地2枚以上でキープ。3回まで)。底に置くのは、余った土地(4枚を超える分)、次に重い呪文。
- **自分のターン(相手側)のメインフェイズ**: 土地を出す → 土地・マナ能力を必要な分だけタップして、唱えられるいちばん重い呪文を唱える。対象を取る呪文は、あなた側のものを対象にする(無ければ唱えない)。唱えたら、スタックに積んで止まる(あなたが応答できる。「次へ」で解決)。
- まだしないこと: あなたの呪文への応答、マナ以外の起動型能力。攻撃できるクリーチャーがいても、相手の戦闘ステップは飛ばす。
- 設定「対戦の相手」で、「何もしない」にもできる(自分の操作の確認用)。新しく始める対戦から反映。

### 対戦の画面(時間ゲージ)

- 真ん中の帯の底に、黄色い時間ゲージ。**「何もできないとき、ゲージで自動で進む」(既定)で、何もできないステップ**(土地を出せない・唱えられない・使える能力が無い。土地やカードの能力のマナを全部出したと仮定)は、3秒かけて左から右へ進み、終わったら次のステップへ自動で進む(「次へ」で、待たずに進める)。相手のターンも同じ。
- できることがあるとき・「毎回止まる」のときは、ゲージは満タンのまま動かない(自分で「次へ」を押すまで待つ)。質問や対象選びの途中も進まない。

### 対戦の画面(ターン表示)

- 真ん中の赤い帯に、「あなたのターン / 相手のターン」(緑 / オレンジ)、フェイズの進み(5つ。いまのものが紫)、ターン数とステップを出す。外枠と、そのターンのプレイヤーのアバターも、同じ色で光る。

### 対戦の画面(段階4c: マリガンと止まり方)

- 対戦の開始前に、ロンドン・マリガン。手札を見て「キープ」か「マリガン」(手札を戻して切り、7枚引き直す)。キープすると、マリガンした回数ぶん、手札から選んでライブラリーの底に置く(Esc で選び直し)。相手は常にキープ。終えるまで、カードは使えず、「次へ」も押せない。
- 設定「対戦の止まり方」: **使えるものがあるときだけ止まる**(既定)は、(土地・マナ能力のあるカードのマナを全部出したとして)土地を出せる・唱えられる呪文・使える能力があるステップだけで止まる。何もできなければ、メインフェイズも飛ばす。相手のターンも同じ。**毎回止まる**は、ステップごとに止まる(相手のターンも)。相手のターンで止まるときは、自分に優先権があり、インスタントを唱えられる。

### 対戦の画面(段階4b: 入力待ち)

- 自分への質問は、画面で答える: **手札を捨てる**(捨てる効果は、捨てるカードを選ぶ。ターン終了で 7 枚を超えたときは、**残す 7 枚を選ぶ**。選ばなかったものが墓地へ)、**ライブラリーの上から選ぶ**、**ライブラリーの上・底に置く順番を選ぶ**(カードを上にしたい順にクリック。番号が付く)、**「してもよい」**(はい/いいえ)、**「支払わないかぎり」**(支払う/支払わない)、**誘発型能力の対象**。
- 答えるまで、局面は変わらない。**Esc**で取り消すと、何も起きなかったことになる(使おうとしたカードも手札のまま)。
- 相手への質問は、これまでどおり自動。

### 対戦の画面(段階4a: 対象を選んで使う)

- 対象を取るカード・能力は、ダブルクリックすると、合法な対象(戦場のカード・アバター・スタックの呪文)が黄色く光る。クリックで選ぶ(もう一度で解除)。選んでいる間は、右下の「次へ」ボタンが「確定 (1 / 1)」になり、数が足りたら押せる(上の帯は出さない)。**Esc** で取り消し(何も変わらない)。対象が複数のカードは、順番に聞く(最後の対象まで「次の対象へ」)。
- 対象にできるものが無いカードは、使えない(ログに理由が出る)。

### 対戦の画面(段階3: 自分のターンの操作)

- **ダブルクリック**で使う: 手札のカード(土地は出す・それ以外は唱える)。1回クリックは選択とプレビュー。使えるものは、緑の枠で光る。
- 能力が2つ以上あるカード: 1回クリックで能力の一覧。ダブルクリックなら、一番上の使える能力。**Esc** か他の場所のクリックで閉じる。
- 右下の「次へ」(スタックにものがあれば「解決する」)でステップを進める。相手のターンは、自動で飛ばす(相手は何もしない)。
- 手札が7枚を超えたときは、後ろから自動で捨てる。

### 対戦の画面(段階2: 対戦を始める)

- コマンド「Battle: start battle」で、自分のデッキを選ぶ。相手のデッキは、同じフォーマットで使えるデッキから選ぶか、ランダム。統率戦のデッキは、まだ使えない。ルールが設定されていないカード(`Rules/` にノートが無い・ノードが空)は、始める前に一覧で出る。そのまま始めると、そのカードを使ったとき、「ルールが設定されていません。スキップします。」とログに出て、効果は飛ばされる(基本土地も、ルールが無ければマナが出ない)。
- 山札を切って、手札7枚ずつで始まる(自分が先手、マリガンは無し、ライフ 20)。
- プレインズウォーカーの忠誠度は、カードのノートの `loyalty:` から読む。古いノートは、デッキ画面の「情報取得」で付く。

### 対戦の画面(段階1: 盤面を見るだけ)

- コマンド「Battle: open battle screen (sample)」で、サンプルの局面を表示する画面が開く。操作はまだ無く、見た目の確認用。
- 斜め見下ろしの盤面。奥が相手、手前が自分。手札は手前にこちら向きで並び、カーソルを合わせたカードが前に出る。左下が自分、右上が相手のライフ。赤い帯が戦闘のライン (攻撃クリーチャーは紫に光る)。右のフェイズ表示は、開始・戦闘前メイン・戦闘・戦闘後メイン・最終 (その下に、いまのステップ)。
- 相手の手札は盤面に出さない。山札・墓地は、盤面の上に立体で置く (相手は左上から、自分は右下から縦に並ぶ。相手側は相手の向き (180 度回転) で、自分側の点対称になる)。山札の絵 (Scryfall の公式のカードの裏面の画像) と、枚数に応じた厚み(10 枚ごとに 1 層。ドレッジなどで、枚数を見た目でも確かめられる)で見せる。
- 同じ名前の土地は、1つの山にまとめて重ねる (枚数つき)。タップした土地は、横向きに倒して、山の脇に並ぶ。
- 右のサイドバー: 上 = カーソルを合わせたカードの画像と効果テキスト、下 = 対戦のログ。画像は、`Cards/` のノートに保存済みのものを使う (新しい通信はしない)。
- 設計と段階は `docs/superpowers/specs/2026-11-04-battle-ui-design.md`。

対戦機能の核を作っている途中で、対戦の画面はまだ無い。カードの能力を、汎用のノードの組み合わせで `Rules/<カード名>.md` に書く(Obsidian 上で手で直せる)。

- コマンド「Battle: create sample rules」で、打ち消し3種(Negate / Essence Scatter / Spell Snare)のサンプルを `Rules/` に作る。
- コマンド「Battle: rules coverage」で、`Cards/` の全カードの状況(ok / partial / unbuilt)を `Rules/_coverage.md` に書き出す。ok は、最小シナリオを実際に動かして通ったものだけ。
- いま使えるノード: `target`(対象。スタックの呪文、戦場のパーマネント、プレイヤー。`controller` で自分のもの・相手のものに絞れる。呪禁のパーマネントは相手の対象にならない)、`counter`(打ち消す。`unlessPay` で「支払わないかぎり」)、`draw`(引く)、`discard`(捨てる)、`bounce`(手札に戻す)、`tap` / `untap`、`modify`(+X/+Y の修整)、`grant`(キーワードを得る。持続は「ターン終了時まで」か forever)、`cost`(起動型能力のコスト。マナ(`mana=` 汎用、`manaCost="{1}{U}"` 色つき)・タップ・生け贄・クリーチャーのタップ)、`additionalCost`(呪文の追加コスト。キッカー・チームワーク)、`addMana`(マナを加える。`color=W/U/B/R/G/C/any` で色)、`modes`(「以下から選ぶ」。各モードのノードに `if=mode1` …)、`when`(誘発型能力の最初に書く、誘発のきっかけ:呪文を唱えた・戦場に出た・戦場を離れた)、`self`(このパーマネント自身)、`addCounter`(+1/+1 カウンターと麻痺カウンター)、`keyword`(常在型能力に書く、瞬速などのキーワードの宣言)、`affect` と継続効果のノード(`staticModify`・`staticGrant`・`loseAbilities`・`setBaseStats`・`setTypes`・`setColors`・`setName`・`extraTriggers`。装備・オーラ・常在型能力。レイヤーの順に計算する)、`attach`(装備品・オーラを付ける)、`cost loyalty=N`・`loyaltyX=true`(プレインズウォーカーの忠誠度能力。ソーサリーのタイミングで1ターンに1回)、`createToken`・`createEmblem`/`emblem`(トークンと紋章)、`countCards`・`filter`(枚数を数える・絞り込む)、`choose atMost=true`、`when event=step`(ステップの開始時)、`addMana` の `spellType`/`spellNotType`(使い道に制限のあるマナ)、数の引数への参照(`$X`、`count=$n`)と、型の `|`(または)、`timing`(装備などのソーサリーのタイミング)、`untapDuring`(他のプレイヤーのアンタップ・ステップにもアンタップ)、`when event=attacks / blocks`(攻撃・ブロックしたとき。戦闘そのものはエンジンが処理する)、`ward`(護法 {N})、`## 準備呪文`・`prepareSpell`・`entersPrepared`・`prepare`(準備済)、`exile`(墓地から追放)、条件 `if=$名前`(「そうしたなら」)、`gainLife` / `loseLife` / `damage`(ライフとダメージ。`target zone=any` はプレイヤー・クリーチャー・プレインズウォーカー)、`reduceCost`(コスト軽減。`payManaCosts` のときだけ、カード自体のマナコストを払う)、`select`(「すべての〜」。対象を取らない)、`look` / `choose` / `move`(ライブラリーの上から見る・選ぶ・手札や底に動かす)、`lookHand`(プレイヤーの手札を見る。`filter`・`choose`・`move` につなぐと、「相手の手札を見て、1枚選んで、捨てさせる」(Duress と同じ形)になる)。`target` は `min` / `max` で複数の対象(「1体か2体」「最大1つ」)、`attacking` / `tapped` で絞れる。ここにない効果は、AI が `## 未対応` に書く。
- 条件 `if=`: どのノードにも `if=<条件>` を付けると、その条件のときだけ実行される(否定は `if=!<条件>`)。いまの条件は `kicked`(キッカーされた)、`teamwork`(チームワークを用いた)、`mode1`〜`mode5`(そのモードが選ばれた)と、数の条件 `<場所>:<型>:<数>[+|-]`(例: `graveyard:lesson:3+` = 自分の墓地に Lesson が3枚以上)。「〜なら」「代わりに」は、条件と否定のノードを並べて表す。ノード設定画面のカードの「条件」では、`kicked` などの名前のある条件を選べる(数の条件は、md に書く。md に書いてあれば、画面にも出る)。
- 設定の「AI」で、Claude の API キーを選ぶ(Obsidian のキーチェーンに保存され、`data.json` には保存先の名前だけが残る)。モデルも設定で変えられる(既定は `claude-opus-5-5`)。
- コマンド「Battle: create glossary note」で、AI に教える用語集(パーマネントの範囲、誘発型・起動型・常在型の見分け方など)の既定(英語)から、`Rules/_glossary.md` を作る。作ったノードを直すと、その内容が既定のかわりに AI へ渡る。
- コマンド「Battle: build rules with AI」で、カードを選ぶ画面が開く。チェックしたカードだけを、AI がノードの組み合わせに直して `Rules/<カード名>.md` に作る。初期のチェックは、ルールがまだ無いカードと、ノートに `## 未対応` が残っているカード(新しいノードで組めるようになったかもしれないので、頼み直せる。一覧には「ルールなし(未対応あり)」と出る)。公式のテキストや裁定が変わったときは、画面の「裁定後のテキスト」に新しい文章を入れて、1枚だけ選んで実行すると、AI がそれを正しいテキストとして組み直す。ルールがあるカードを選ぶと上書きになり、元の内容は履歴として残る(下の「ルールの履歴」)。AI の返事は、読み込みと検証を通ったものだけを保存する。ノードで表せない部分は、md の `## 未対応` に書かれ、状況は partial になる。API の料金がかかる。
- コマンド「Battle: edit rule nodes」(`Rules/<カード名>.md` か `Cards/<カード名>.md` を開いて実行)で、ノード設定画面が開く。能力ごとの列に、ノードのカードが実行順に並ぶ。右のパレットからノードをドラッグ(またはクリック)して追加し、カードの見出しをドラッグして並べ替え、出力の点(カードの `as` の右)から、後ろのノードの入力の点(左の丸)へドラッグしてつなぐ。引数は、カードの中の入力欄で直す。問題があるノードは赤くなり、直すまで保存できない。「保存」を押すと、システムが前の内容を履歴に残してから md を書く。ノードの位置は md に書けないので、実行順から毎回決まる。
- ルールの履歴: AI が作り替える前、ノード設定画面(あとで作る)で直す前、版を戻す前の内容が、`Rules/_backup/<カード名>/<日時>-<種類>.md`(種類は `ai` / `edit` / `restore`)に、版ごとに1ファイルで残る。履歴を残すのは、システムが保存するときだけ。md を直接書き換えた分は、保存のタイミングが分からないので、履歴に残らない。コマンド「Battle: restore rule version」で、開いているルールの版を一覧から選んで戻せる。戻す前の内容も履歴に入る。

## フォーマットのルール

デッキのノートの `format:` で決まる(Standard / Pioneer / Modern / Legacy / Vintage / Pauper / Commander。作成時に選ぶ)。`format:` が無い・知らないデッキは「制限なし」(同名4枚とサイド15枚だけ)。

- **60枚のフォーマット**: 同名カードはメインとサイドの合計で4枚まで(基本土地と、枚数の例外が書かれたカードを除く)、サイドは15枚まで。Vintage の制限カードは、メインとサイドの合計で1枚まで。
- **Commander**: コマンダー欄(1体。伝説のクリーチャーか「コマンダーにできる」カード)、同名1種(基本土地と例外を除く)、コマンダーを含めて100枚。伝説のカードにホバーして👑で指定、もう一度押すと解除。色の同一性とパートナーは未対応。
- そのフォーマットで使えないカード(禁止など)は、一覧で薄くなり、追加できない。コマンダーがいるデッキは、Commander 以外のフォーマットでは使えない扱い。
- 取り込み(Import)には制限をかけない。
- カードの使えるフォーマットは、カードのノートの `legal:` と `restricted:` に記録される。取得前のカードは、コマンド「Update card legality」で手動更新する(Vintage のデッキに足すときは、そのカード1枚だけ自動で確認する)。

## ノートの形式

| 場所 | 内容 |
|---|---|
| `Cards/<カード名>.md` | カード名、マナコスト、タイプ、効果テキスト、画像、収録一覧(Printings の表)、`legal:` / `restricted:`。設定した言語の名前は `name_local:` |
| `Decks/<デッキ名>.md` | `## Main` / `## Side`(統率戦は `## Commander` / `## Main`)に、`4 [[Lightning Bolt]] (m11 149)` の形で1行ずつ。`format:` `favorite:` `thumbnail:` |
| `Collection/<セット>.md` | `3 [[Lightning Bolt]] (149) LP foil` の形で1行ずつ(セットはファイル名、括弧は番号、状態と foil は省略可) |

検索は `Cards/` の結果に、Scryfall の結果のうち `Cards/` に無いカードを足して出す(同じ検索語は画面を開いている間は覚えて、API を呼び直さない)。追加したカードはノート化される。
