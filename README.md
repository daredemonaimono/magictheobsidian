# Magic the Obsidian

Obsidian を Magic: The Gathering のデッキ構築ツールにするプラグインです。カードは Scryfall から取得してノート(md)になり、デッキ・コレクションもノートで保存されます。

## BRAT でのインストール

1. Obsidian に BRAT プラグインを入れる。
2. BRAT の「Add Beta plugin」に `daredemonaimono/magictheobsidian` を入力する。
3. 設定の Community plugins で「Magic the Obsidian」を有効にする。

## 画面

### ダッシュボード

- コマンド「Open dashboard」か、左のリボンのアイコンで開く。新しいタブ(空のタブ)もダッシュボードになる(設定でオフ可)。
- 「コレクション」「デッキ」「カード」の3つのボタンから、各画面を開く。

### デッキ一覧(ダッシュボード → デッキ)

- All / お気に入りのタブ、名前の検索、使えるフォーマットでの絞り込み(デッキ内の全カードが使えるフォーマット。コマンダーがいるデッキは Commander のみ)。
- 「＋ 新しいデッキ」。窓で名前・フォーマットを選び、Moxfield のテキストを貼ると取り込んで作る(空なら空のデッキ)。
- カードにホバーすると、🗑(デッキのノートごと削除。確認あり。Obsidian の「削除したファイルの行き先」に従う)、♡(お気に入り、`favorite: true`)、🖼(サムネイル、`thumbnail:`)。サムネイルは、デッキで使っているカードアート(デッキで選んだ版)から選ぶ。

### デッキ画面

- コマンド「Create deck」で、デッキ名とフォーマットを選んで作る。`Decks/` にノートができ、専用の画面が開く。既存のデッキのノートは、コマンド「Open current deck in deck view」で画面にできる。
- 上にヘッダー(Moxfield 風)がある。ヘッダー画像(デッキのカードアート。デッキ一覧のサムネイルと同じもので、frontmatter の `thumbnail:`。デッキ一覧で変えると、ヘッダーにも反映される)、デッキ名、フォーマット(選んで変更。いまのデッキが使えるかを ○/×/？ で表示)、更新日時、説明文(`description:`)。フォーマットは選んで、説明文はクリックして編集する。ヘッダー画像は、デッキ一覧の🖼で設定する。下のバーに、メイン/サイドの枚数、デッキの合計価格(コレクションの通貨・価格を使う)、資産(コレクション)に無いカードの差額(同じカードの所持枚数で数える。版は問わない。基本土地は数えない)、タイプ別の枚数が出る。
- カードはタイプ別の見出しに重ねて並ぶ。見出しの並びは全フォーマット共通で、「Commander / Planeswalker / Creature」「Sorcery / Instant」「Artifact / Enchantment / Battle」「Land」の列。ホバーすると、左に拡大画像と効果テキストが出る。
- 重ねたカードにホバーすると、🖼(イラスト=収録セットの選択。選んだ版は `4 [[Lightning Bolt]] (m11 149)` のようにノートに保存)が出る。枚数の増減は、右サイドバーの一覧で行う。名前が `A // B` のカード(両面・冒険・準備など)には ↩︎ も出て、押すと裏面になる(裏面の画像があるカードは画像、無いカードは裏面のテキスト。左のプレビューも合わせる)。コレクション画面とカード一覧にも、同じ ↩︎ がある。
- メイン/サイドのタブを押すと、サイドバーが畳まれていれば開く。タブの右の「情報取得」で、トークンを含むデッキ内の全カードの情報を Scryfall から取る(手動)。設定言語のテキスト(`## Text (ja)` など)が無いカード、パワー・タフネス(`power:`/`toughness:`)やキーワード(`keywords:`)が無いクリーチャーは取り直して補い(あるものは触らない)、リーガル情報が無いカードを補い、価格も取り直す。フォーマットはヘッダーで変えられる(統率戦とそれ以外のあいだは不可)。
- トークン(タイプが Token のカード)は、メイン/サイドとは別枠の `## Token` 欄に入り、Land の右の「Token」見出しに並ぶ。フォーマットのルール(使用可否・枚数)と、枚数・価格・○/×の数には入らない。
- ノートの末尾に「動き方」欄(勝ち筋・序盤・中盤・注意点)ができる。自由に書き換えてよく、画面の操作では消えない。
- デッキのノートはカードへのリンクなので、グラフビューでカードの採用率が見える。

### サイドバーのカード一覧(デッキ画面用)

- デッキ画面を開くと、右サイドバーにカード一覧のタブが置かれ、サイドバーが開いて一覧が前に出る(サイドバーを閉じていても出る)。デッキ画面が全部閉じるとアイコンごと消え、一覧が見えていたならサイドバーも畳む。開いているデッキ(タブを切り替えたデッキ)に追従する。デッキ画面以外のタブに切り替えるとサイドバーは畳まれ、デッキ画面に戻ると開き直す。
- デッキ名の横のボタン(メイン/サイド。統率戦のメインはコマンダー込み)で切り替える。デッキ画面のタブも同じに切り替わり、検索から追加するカードの行き先もその欄になる。
- 普段は、いま選んだ欄に入っているカード(枚数つき)を並べる。クリックで+1、Shift+クリックで−1(そのカードがいる欄の枚数)。そのフォーマットで使えないカードは赤く先頭に出る。
- 「＋ 新しく追加」で条件(名前・効果・タイプ・色・デッキ内のカードも含めるか・トークンも含めるか。タイプに「トークン」もある)を入れて検索すると結果に切り替わり、クリックで追加、Shift+クリックで1枚削除。「← デッキ内に戻る」で戻る。
- 並びは、デッキ画面の見出しと同じ順で、同じ見出しの中はコスト順。コストと色はマナシンボルのアイコン(画像は Scryfall から読み込む)。イラストを薄く出せる(設定でオフ可)。
- 設定の「カード一覧をサイドバーに出す」をオフにすると、デッキ画面の中の検索欄に戻る。

### コレクション

- コマンド「Open collection」か、ダッシュボードの「コレクション」。「Add cards」で検索して追加する。
- グリッド/リスト表示。セット・色・名前で絞り込み。版ごとの価格と合計。通貨は設定で選ぶ(既定は USD)。Scryfall の USD(TCGplayer の価格)が無いカードは、EUR(Cardmarket の価格)を、為替レート(Frankfurter)で設定の通貨に換算して出す。レートは価格の更新と、通貨を変えたときに取る。価格は「価格を更新」ボタンかコマンド「Update collection prices」で手動更新する(自動では取得しない)。
- 行ごとに状態(NM/LP/MP/HP/DMG)と foil を記録する。グリッド表示では foil のカードに虹色の光(動かない)を重ねる。ホバーで1枚だけ変更できる。

### カード一覧(ダッシュボード → カード)

- `Cards/` のカードを、フィルター付きで見る。クリックでカードのノートが開く。
- ホバーして「↻」で、そのカードだけ Scryfall から取り直す。frontmatter は取り直した項目だけ上書きし、本文は作り直す(本文に書いたメモは消える)。
- 効果テキストの言語が日本語のときは「Wiki」で、MTG Wiki のそのカードのページをブラウザで開く。

## 対戦(作成中)

対戦機能の核を作っている途中で、対戦の画面はまだ無い。カードの能力を、汎用のノードの組み合わせで `Rules/<カード名>.md` に書く(Obsidian 上で手で直せる)。

- コマンド「Battle: create sample rules」で、打ち消し3種(Negate / Essence Scatter / Spell Snare)のサンプルを `Rules/` に作る。
- コマンド「Battle: rules coverage」で、`Cards/` の全カードの状況(ok / partial / unbuilt)を `Rules/_coverage.md` に書き出す。ok は、最小シナリオを実際に動かして通ったものだけ。
- いま使えるノード: `target`(対象。スタックの呪文、戦場のパーマネント、プレイヤー。`controller` で自分のもの・相手のものに絞れる。呪禁のパーマネントは相手の対象にならない)、`counter`(打ち消す。`unlessPay` で「支払わないかぎり」)、`draw`(引く)、`discard`(捨てる)、`bounce`(手札に戻す)、`tap` / `untap`、`modify`(+X/+Y の修整)、`grant`(キーワードを得る。持続は「ターン終了時まで」か forever)、`cost`(起動型能力のコスト。マナ・タップ・生け贄・クリーチャーのタップ)、`additionalCost`(呪文の追加コスト。キッカー・チームワーク)、`addMana`(マナを加える)、`modes`(「以下から選ぶ」。各モードのノードに `if=mode1` …)、`when`(誘発型能力の最初に書く、誘発のきっかけ:呪文を唱えた・戦場に出た・戦場を離れた)、`self`(このパーマネント自身)、`addCounter`(+1/+1 カウンターと麻痺カウンター)、`keyword`(常在型能力に書く、瞬速などのキーワードの宣言)、`affect` と継続効果のノード(`staticModify`・`staticGrant`・`loseAbilities`・`setBaseStats`・`setTypes`・`setColors`・`setName`・`extraTriggers`。装備・オーラ・常在型能力。レイヤーの順に計算する)、`attach`(装備品・オーラを付ける)、`cost loyalty=N`・`loyaltyX=true`(プレインズウォーカーの忠誠度能力。ソーサリーのタイミングで1ターンに1回)、`createToken`・`createEmblem`/`emblem`(トークンと紋章)、`countCards`・`filter`(枚数を数える・絞り込む)、`choose atMost=true`、`when event=step`(ステップの開始時)、`addMana` の `spellType`/`spellNotType`(使い道に制限のあるマナ)、数の引数への参照(`$X`、`count=$n`)と、型の `|`(または)、`timing`(装備などのソーサリーのタイミング)、`untapDuring`(他のプレイヤーのアンタップ・ステップにもアンタップ)、`reduceCost`(コスト軽減。`payManaCosts` のときだけ、カード自体のマナコストを払う)、`select`(「すべての〜」。対象を取らない)、`look` / `choose` / `move`(ライブラリーの上から見る・選ぶ・手札や底に動かす)。`target` は `min` / `max` で複数の対象(「1体か2体」「最大1つ」)、`attacking` / `tapped` で絞れる。ここにない効果は、AI が `## 未対応` に書く。
- 条件 `if=`: どのノードにも `if=<条件>` を付けると、その条件のときだけ実行される(否定は `if=!<条件>`)。いまの条件は `kicked`(キッカーされた)、`teamwork`(チームワークを用いた)、`mode1`〜`mode5`(そのモードが選ばれた)と、数の条件 `<場所>:<型>:<数>[+|-]`(例: `graveyard:lesson:3+` = 自分の墓地に Lesson が3枚以上)。「〜なら」「代わりに」は、条件と否定のノードを並べて表す。ノード設定画面のカードの「条件」では、`kicked` などの名前のある条件を選べる(数の条件は、md に書く。md に書いてあれば、画面にも出る)。
- 設定の「AI」で、Claude の API キーを選ぶ(Obsidian のキーチェーンに保存され、`data.json` には保存先の名前だけが残る)。モデルも設定で変えられる(既定は `claude-opus-5-5`)。
- コマンド「Battle: create glossary note」で、AI に教える用語集(パーマネントの範囲、誘発型・起動型・常在型の見分け方など)の既定(英語)から、`Rules/_glossary.md` を作る。作ったノードを直すと、その内容が既定のかわりに AI へ渡る。
- コマンド「Battle: build rules with AI」で、カードを選ぶ画面が開く。チェックしたカードだけを、AI がノードの組み合わせに直して `Rules/<カード名>.md` に作る。初期のチェックは、ルールがまだ無いカード。公式のテキストや裁定が変わったときは、画面の「裁定後のテキスト」に新しい文章を入れて、1枚だけ選んで実行すると、AI がそれを正しいテキストとして組み直す。ルールがあるカードを選ぶと上書きになり、元の内容は履歴として残る(下の「ルールの履歴」)。AI の返事は、読み込みと検証を通ったものだけを保存する。ノードで表せない部分は、md の `## 未対応` に書かれ、状況は partial になる。API の料金がかかる。
- コマンド「Battle: edit rule nodes」(`Rules/<カード名>.md` か `Cards/<カード名>.md` を開いて実行)で、ノード設定画面が開く。能力ごとの列に、ノードのカードが実行順に並ぶ。右のパレットからノードをドラッグ(またはクリック)して追加し、カードの見出しをドラッグして並べ替え、出力の点(カードの `as` の右)から、後ろのノードの入力の点(左の丸)へドラッグしてつなぐ。引数は、カードの中の入力欄で直す。問題があるノードは赤くなり、直すまで保存できない。「保存」を押すと、システムが前の内容を履歴に残してから md を書く。ノードの位置は md に書けないので、実行順から毎回決まる。
- ルールの履歴: AI が作り替える前、ノード設定画面(あとで作る)で直す前、版を戻す前の内容が、`Rules/_backup/<カード名>/<日時>-<種類>.md`(種類は `ai` / `edit` / `restore`)に、版ごとに1ファイルで残る。履歴を残すのは、システムが保存するときだけ。md を直接書き換えた分は、保存のタイミングが分からないので、履歴に残らない。コマンド「Battle: restore rule version」で、開いているルールの版を一覧から選んで戻せる。戻す前の内容も履歴に入る。

## フォーマットのルール

デッキのノートの `format:` で決まる(Standard / Pioneer / Modern / Legacy / Vintage / Pauper / Commander。作成時に選ぶ)。`format:` が無い・知らないデッキは「制限なし」(同名4枚とサイド15枚だけ)。

- **60枚のフォーマット**: 同名カードはメインとサイドの合計で4枚まで(基本土地と、枚数の例外が書かれたカードを除く)、サイドは15枚まで。Vintage の制限カードは、メインとサイドの合計で1枚まで。
- **Commander**: コマンダー欄(1体。伝説のクリーチャーか「コマンダーにできる」カード)、同名1種(基本土地と例外を除く)、コマンダーを含めて100枚。伝説のカードにホバーして👑で指定、もう一度押すと解除。色の同一性とパートナーは未対応。
- そのフォーマットで使えないカード(禁止など)は、一覧で薄くなり、追加できない。コマンダーがいるデッキは、Commander 以外のフォーマットでは使えない扱い。
- 取り込み(Import)には制限をかけない。
- カードの使えるフォーマットは、カードのノートの `legal:` と `restricted:` に記録される。取得前のカードは、コマンド「Update card legality」で手動更新する(Vintage のデッキに足すときは、そのカード1枚だけ自動で確認する)。

## ノートの形式

| 場所 | 内容 |
|---|---|
| `Cards/<カード名>.md` | カード名、マナコスト、タイプ、効果テキスト、画像、収録一覧(Printings の表)、`legal:` / `restricted:`。設定した言語の名前は `name_local:` |
| `Decks/<デッキ名>.md` | `## Main` / `## Side`(統率戦は `## Commander` / `## Main`)に、`4 [[Lightning Bolt]] (m11 149)` の形で1行ずつ。`format:` `favorite:` `thumbnail:` |
| `Collection/<セット>.md` | `3 [[Lightning Bolt]] (149) LP foil` の形で1行ずつ(セットはファイル名、括弧は番号、状態と foil は省略可) |

検索は `Cards/` の結果に、Scryfall の結果のうち `Cards/` に無いカードを足して出す(同じ検索語は画面を開いている間は覚えて、API を呼び直さない)。追加したカードはノート化される。

## コマンド

- Fetch card from Scryfall / Create deck / Import deck (Moxfield text)(`4 Lightning Bolt (M11) 149`、`SIDEBOARD:` 区切り。カードは版まで指定して取得)
- Open dashboard / Open collection / Open current deck in deck view
- Update collection prices / Update card legality (cards without it)

## 設定

- 価格の通貨
- 効果テキストの言語、カード(画像)の言語(新しく取得するカードから反映)
- カード一覧をサイドバーに出す / 一覧にイラストを出す / 新しいタブをダッシュボードにする

## ビルド

```bash
npm install
npm run build   # main.js が生成される
```

## リリース

`manifest.json` の version と同じタグでリリースを作り、`main.js`・`manifest.json`・`styles.css` を添付します。

## クレジット

カードデータと画像は [Scryfall](https://scryfall.com/) の API を使っています。日本語のカード情報のページは [MTG Wiki](https://mtgwiki.com/) へのリンクで開きます(内容は取り込みません)。Magic: The Gathering は Wizards of the Coast の商標です。このプラグインは非公式です。
