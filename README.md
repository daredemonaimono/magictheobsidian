# Magic the Obsidian

Obsidian を Magic: The Gathering のデッキ構築ツールにするプラグインです。カードは Scryfall から取得してノート(md)になり、デッキ・コレクションもノートで保存されます。

## BRAT でのインストール

1. Obsidian に BRAT プラグインを入れる。
2. BRAT の「Add Beta plugin」に `daredemonaimono/magictheobsidian` を入力する。
3. 設定の Community plugins で「Magic the Obsidian」を有効にする。

## 画面

### ダッシュボード

- コマンド「Open dashboard」か、左のリボンのアイコンで開く。新しいタブ(空のタブ)もダッシュボードになる(設定でオフ可)。
- 「コレクション」「デッキ」「カード」の3つのボタンから、各画面を開く。

### デッキ一覧(ダッシュボード → デッキ)

- All / お気に入りのタブ、名前の検索、使えるフォーマットでの絞り込み(デッキ内の全カードが使えるフォーマット。コマンダーがいるデッキは Commander のみ)。
- 「＋ 新しいデッキ」。窓で名前・フォーマットを選び、Moxfield のテキストを貼ると取り込んで作る(空なら空のデッキ)。
- カードにホバーすると、🗑(デッキのノートごと削除。確認あり。Obsidian の「削除したファイルの行き先」に従う)、♡(お気に入り、`favorite: true`)、🖼(サムネイル、`thumbnail:`)。サムネイルは、デッキで使っているカードアート(デッキで選んだ版)から選ぶ。

### デッキ画面

- コマンド「Create deck」で、デッキ名とフォーマットを選んで作る。`Decks/` にノートができ、専用の画面が開く。既存のデッキのノートは、コマンド「Open current deck in deck view」で画面にできる。
- 上にヘッダー(Moxfield 風)がある。ヘッダー画像(デッキのカードアート。デッキ一覧のサムネイルと同じもので、frontmatter の `thumbnail:`。デッキ一覧で変えると、ヘッダーにも反映される)、デッキ名、フォーマット(選んで変更。いまのデッキが使えるかを ○/×/？ で表示)、更新日時、説明文(`description:`)。フォーマットは選んで、説明文はクリックして編集する。ヘッダー画像は、デッキ一覧の🖼で設定する。下のバーに、メイン/サイドの枚数、デッキの合計価格(コレクションの通貨・価格を使う)、資産(コレクション)に無いカードの差額(同じカードの所持枚数で数える。版は問わない。基本土地は数えない)、タイプ別の枚数が出る。
- カードはタイプ別の見出しに重ねて並ぶ。見出しの並びは全フォーマット共通で、「Commander / Planeswalker / Creature」「Sorcery / Instant」「Artifact / Enchantment / Battle」「Land」の列。ホバーすると、左に拡大画像と効果テキストが出る。
- 重ねたカードにホバーすると、🖼(イラスト=収録セットの選択。選んだ版は `4 [[Lightning Bolt]] (m11 149)` のようにノートに保存)、−、+。
- メイン/サイドのタブを押すと、サイドバーが畳まれていれば開く。タブの右の「情報取得」で、トークンを含むデッキ内の全カードの情報を Scryfall から取る(手動)。設定言語のテキスト(`## Text (ja)` など)が無いカード、パワー・タフネス(`power:`/`toughness:`)やキーワード(`keywords:`)が無いクリーチャーは取り直して補い(あるものは触らない)、リーガル情報が無いカードを補い、価格も取り直す。フォーマットはヘッダーで変えられる(統率戦とそれ以外のあいだは不可)。
- トークン(タイプが Token のカード)は、メイン/サイドとは別枠の `## Token` 欄に入り、Land の右の「Token」見出しに並ぶ。フォーマットのルール(使用可否・枚数)と、枚数・価格・○/×の数には入らない。
- ノートの末尾に「動き方」欄(勝ち筋・序盤・中盤・注意点)ができる。自由に書き換えてよく、画面の操作では消えない。
- デッキのノートはカードへのリンクなので、グラフビューでカードの採用率が見える。

### サイドバーのカード一覧(デッキ画面用)

- デッキ画面を開くと、右サイドバーにカード一覧のタブが置かれ、サイドバーが開いて一覧が前に出る(サイドバーを閉じていても出る)。デッキ画面が全部閉じるとアイコンごと消え、一覧が見えていたならサイドバーも畳む。開いているデッキ(タブを切り替えたデッキ)に追従する。デッキ画面以外のタブに切り替えるとサイドバーは畳まれ、デッキ画面に戻ると開き直す。
- デッキ名の横のボタン(メイン/サイド。統率戦のメインはコマンダー込み)で切り替える。デッキ画面のタブも同じに切り替わり、検索から追加するカードの行き先もその欄になる。
- 普段は、いま選んだ欄に入っているカード(枚数つき)を並べる。クリックで+1、Shift+クリックで−1(そのカードがいる欄の枚数)。そのフォーマットで使えないカードは赤く先頭に出る。
- 「＋ 新しく追加」で条件(名前・効果・タイプ・色・デッキ内のカードも含めるか・トークンも含めるか。タイプに「トークン」もある)を入れて検索すると結果に切り替わり、クリックで追加、Shift+クリックで1枚削除。「← デッキ内に戻る」で戻る。
- 並びは、デッキ画面の見出しと同じ順で、同じ見出しの中はコスト順。コストと色はマナシンボルのアイコン(画像は Scryfall から読み込む)。イラストを薄く出せる(設定でオフ可)。
- 設定の「カード一覧をサイドバーに出す」をオフにすると、デッキ画面の中の検索欄に戻る。

### コレクション

- コマンド「Open collection」か、ダッシュボードの「コレクション」。「Add cards」で検索して追加する。
- グリッド/リスト表示。セット・色・名前で絞り込み。版ごとの価格と合計。通貨は設定で選ぶ(既定は USD)。Scryfall の USD(TCGplayer の価格)が無いカードは、EUR(Cardmarket の価格)を、為替レート(Frankfurter)で設定の通貨に換算して出す。レートは価格の更新と、通貨を変えたときに取る。価格は「価格を更新」ボタンかコマンド「Update collection prices」で手動更新する(自動では取得しない)。
- 行ごとに状態(NM/LP/MP/HP/DMG)と foil を記録する。グリッド表示では foil のカードに虹色の光(動かない)を重ねる。ホバーで1枚だけ変更できる。

### カード一覧(ダッシュボード → カード)

- `Cards/` のカードを、フィルター付きで見る。クリックでカードのノートが開く。
- ホバーして「↻」で、そのカードだけ Scryfall から取り直す。frontmatter は取り直した項目だけ上書きし、本文は作り直す(本文に書いたメモは消える)。
- 効果テキストの言語が日本語のときは「Wiki」で、MTG Wiki のそのカードのページをブラウザで開く。

### Bot の試し(仮)

- ダッシュボードの「Bot (試し)」か、コマンド「Open bot trial (solo)」で開く。Obsidian 1.11.4 以上が必要(API キーを OS のキーチェーンに保存するため)。
- 設定の「Bot: Claude API キー」でキーを選ぶ(値は `data.json` に書かれない)。
- Bot 画面でデッキ(メインのカードだけ)・モデル(Haiku 5.5 / Sonnet 5.5 / Opus 5.5)・ターン数を選んで開始すると、ボットが自分のデッキを1人で回す。右サイドバーに、カーソルを合わせたカードの効果と、ログ(ボットの選んだ行動と理由、トークン数、費用)が流れる。
- 「思考浅め / 思考深め」を選べる。浅めは思考を止めて出力が減り安いが、判断は浅くなりうる(Opus は止められないので、どちらも浅い思考)。
- 盤面は見下ろし(仮): 上が相手(未実装)、下が自分。場は奥にクリーチャー等、手前に土地(タップで横向き)、右に山札と墓地、下に手札。カードは画像で出る。
- 対戦が終わると、ログとリプレイ用データ(開始時の山札の並びと行動の列)を `Bot/Games/日時 デッキ名.md` に保存する。リプレイ画面はまだ無い。
- エンジンは使い捨ての簡易版: 土地は1ターン1枚・1マナ(色は無視)、呪文の効果は実行しない、相手と戦闘は無い。費用とボットの選び方を見るための試し。

### Bot 対戦(仮)

- ダッシュボードの「Bot 対戦 (仮)」か、コマンド「Open bot battle (you vs bot)」。あなたがプレイヤー1(先攻)、ボットがプレイヤー2。自分とボットのデッキ(メインのカードだけ)、モデル、思考の深さを選んで開始する。
- ルールはエンジンが守る(土地は1ターン1枚、召喚酔い、優先権とスタック、色つきマナの支払い、飛行・速攻・警戒、ブロック、戦闘ダメージ、勝敗)。呪文と能力の効果はまだ実行されず、インスタント・ソーサリーは唱えると墓地に行くだけ。クリーチャーを出して、攻撃とブロックで戦う。
- 操作: 光っているカードをクリックして出す/唱える。「パス」で進む。攻撃するクリーチャーを選んで「攻撃宣言」。ブロックは、自分のブロッカーを選び、次に相手の攻撃クリーチャーを選んで「ブロック確定」。出せるものが無い場面は、自動で進む。
- 右サイドバーに、カードの効果とログ。対戦が終わると `Bot/Games/` にログとリプレイ用データ(seed と全員の答えの列)を保存する。
- **優先権で止まるステップ**: 既定では、メイン1・メイン2・終了ステップでだけ聞かれる(スタックに何かあるときは常に聞かれる)。ステップの帯のラベルをクリックすると、止まる(下線)・止まらないを切り替えられる。マナが残ったままパスしようとすると、1回止めて確かめる(マナはステップの終わりに消えるため)。
- **開始と手札**: 先攻・後攻はダイスで決まり、勝った人が選ぶ。マリガンはロンドン式(引き直して、キープしたあとに、マリガンした回数ぶんをライブラリーの下に置く)。手札が8枚以上でターンを終えるときは、捨てるカードを手札から選ぶ。「タップ状態で出る」(条件なし)の土地は、タップ状態で出る。
- **ルールブック**: ダッシュボードの「ルールブック」(コマンド「Open rulebook」)。保存先は、プラグインの専用フォルダ(`<プラグインのフォルダ>/rulebook/`。vault の索引に入らない隠しフォルダ)で、vault のノートには出ない。タブは3つだけ。
  - **能力**: 共有の能力の辞書。1つの能力につき1つの md(隠しフォルダの `abilities/`)に、**実際の効果**(日本語の標準の文)・**引数**・**照合の例**(英語の原文)・**処理(関数の並び)**が書かれている。カードは、これを `{"ref":"能力のid","args":{...}}` で使うだけ。エンジンが動かす24のキーワード(飛行、トランプルなど)も、能力として並ぶ。使っているカードが多い順で、カード名をクリックするとカードのノートが開く。下の「関数の一覧」に、エンジンにできること(命令、キーワード、ルールなど)と、その実装の状況・実装の説明がある。
  - **カード**: カードごとの割り振りを確認する。「割り振られた能力」(キーワード、共有の能力と引数、カード固有の能力の件数)を、原文と見比べて、**目で確認する**。カード固有の能力(例: 飛行 + 出たとき〜。飛行はキーワードに割り振り、残りは、そのカードだけの能力として処理を作る)は、これまで通り記録に直接書く。「処理を書く」(自然な文で指示 → 案 → 前後を見比べて保存)、「割り振り直す」、記録の直接編集がある。
  - **未処理**: 処理がまだ無い能力(新しいキーワード、新しく出た能力)、カード固有の動かない部分、新しい関数が要る処理(実装待ち)。能力に、指示で**補完**する(「トランプルは、エンジンのキーワードに割り当てる」など)。「原文から補完」は、既にある関数だけで書けて、動作テストに通ったものを、そのまま処理済みにする。補完したあと、割り振られていなかったカードを、割り振り直す(登録済みの能力に似た文があるカードだけ、AI を使う)。
  - **新しいカードを登録すると**: AI が、効果テキストを読んで、①エンジンのキーワードは何も書かない(カードの `keywords` で動く) ②ライブラリの能力に当てはまるものは `ref` で割り振る ③数や色だけが違う、他のカードにも出そうな能力は、新しい能力としてライブラリに登録して `ref` で使う ④そのカードだけの能力は、固有の能力として処理を作る ⑤関数が足りない部分は、仕様書を書いて「実装待ち」に入れる。エンジンもライブラリも知らないキーワード(Kicker など)は、AI を使わずに、未処理の能力として登録される。
  - **既存の記録**: 能力タブの「既存の記録を、能力に分ける」で、今までのカードの記録を、AI が能力ごとに分けて、ライブラリに移す(1枚ずつ、ライブラリを育てながら。直す前の版は残る)。
  - 能力が補完されると、その能力を使っているカードの「動かない部分」は、すぐ消える(カードの記録は、能力を参照しているため)。
  - **似たカードの記録を、例として渡す**: 記録を作る・直すとき、既にある記録の中から、効果テキストが近いカード(未対応の無い記録を少し優先)を最大3件選んで、AI に参考として見せる。
  - **新しい関数**(エンジンのコード)は、Claude Code が、実装待ちの仕様書を読んで、テストつきで足す(AI がアプリの中でコードを書いて動かすことはしない)。実装されて、待っている型が「未実装」でなくなると、元のカードの記録の更新案が(API キーがあれば自動で)作られる。
  - 旧い置き場(vault の `Bot/Rules/`, `Bot/Types/`)のノートは、更新後の最初の起動で、ルールブックへ移し、vault のノートは Obsidian のゴミ箱へ送る(戻せる)。`Bot/Games/` と `Bot/Diagnostics/` は、vault に残る。
- **診断**: デッキ画面の「診断」で、デッキの全カードについて、エンジンが理解した内容(日本語)を原文と並べたノートを `Bot/Diagnostics/<デッキ名>.md` に作って開く。記録の有無・古さ・未対応、パワー・タフネスとキーワードの未取得、動作テスト(仮の盤面でそのカードを唱える・起動して、最後まで動くかを調べる。API は使わない)の結果が出る。問題のあるカードが先頭に並ぶ。
- **戦闘のキーワード**(エンジンの固定ルール、カードごとの記録は不要): 飛行、到達、速攻、警戒、瞬速、トランプル、先制攻撃、二段攻撃、接死、絆魂、威迫、防衛、破壊不能、呪禁、被覆、威嚇、畏怖、忍び足、影、土地渡り(島・沼・山・森・平地)。キーワードは、Scryfall の `keywords`(カードのノートの `keywords:`。言語に依らず英語)と、英語のオラクルテキストから読むので、日本語など他の言語のカードでも判定は同じ。サイドバーのカード効果の上に、設定の言語(日本語のみ対応、他は英語)でキーワード名を出す。1体の攻撃を複数でブロックできる。
- **ボットに渡す説明**: 「エンジンが実行できること / まだできないこと」を、カテゴリ(命令、誘発のきっかけ、コスト、キーワード、ルール)ごとにまとめて渡す。デッキのカードは、種類(クリーチャー / 呪文 / 土地 / その他)ごとに並べ、カードごとに、原文、エンジンの理解(日本語)、使っている型、動かない部分を付ける。
- **マナは手でタップする**: 土地などをクリックしてマナプールに出し(色が選べる土地は色を選ぶ)、光るカードをクリックして唱える。プールで足りないカードは薄い枠になる。プールはステップの終わりに空になる。ボットは唱えるとき自動でタップする。
- **カードの処理の記録**: デッキ画面の「ルール化」で、デッキのカードのうち記録が無いものを、AI(Sonnet 5.5)が効果テキストから作り、ルールブック(隠しフォルダ)に保存する(初回だけ)。以後はエンジンが機械的に実行し、対戦中に AI は解釈しない。ルールブック画面から直せる(直したものは `status: manual` になり、上書きされない)。
  - 書き方(v3): 効果は「命令」の並び。命令は、何を(カードの選び方)・どこで(山札・手札・戦場・墓地・追放)・どうする・どれだけ・誰が選ぶか、の穴を埋める形で書く。「移す」1つで、ドロー、捨てる、破壊、追放、手札に戻す、ミル、サーチ、蘇生を表す。ほかに、ライフの増減・ダメージ(変える)、マナを出す、シャッフル、コイン投げ、もし〜なら、してもよい。対象は、唱えるとき・起動するときに選び(誘発は解決時)、消えていたら不発になる。
  - **自動で作る**: Bot 対戦を始めるとき、処理の記録が**無い**カードだけ、自動で作る(設定でオフにできる)。既に記録があるカードは、一部未対応でも古くても、作り直さない(トークンを使わない)。古い版の「一部未対応」を作り直すのは、デッキ画面の「ルール化」ボタンだけ。
  - **常在型能力**(戦場にある間ずっと働く能力): いまは「起動の禁止」(Null Rod、Collector Ouphe。マナ能力も止まる)だけ。パワー・タフネスの修整、コストの増減、キーワードの付与、攻撃・ブロックの制限は、これから。
  - **代替コスト**(Fireblast の「山を2つ生け贄」、Force of Despair の「手札から色のカードを追放」など): マナコストの代わりに払うコストで唱えられる。生け贄、手札から追放、ライフ、別のマナコスト、「自分のターンでないとき」の条件を組み合わせられる。人は、手札のカードをクリックして、通常のコストか代替コストかを選ぶ。
  - **コピー**(Fork、Chain Lightning): スタックの呪文のコピーを作る。コピーは先に解決され、持つ人は新しい対象を選んでもよい。「してもよい」には、決める人(対象のコントローラーなど)と、払うマナ(RR)を指定できる。
  - **待機**(Rift Bolt): 手札から待機コストを払って追放し、時間カウンターを置く。自分のアップキープに1つ取り除き、0になったらマナコストを払わずに唱えてもよい。
  - **トークン・カウンター**(Amass): トークンを作る(戦場を離れたら消える)、パーマネントに +1/+1 カウンターを置く(パワー・タフネスに足される。戦場を離れると元の姿に戻る)、サブタイプを加える。0/0 のトークンも、カウンターを置く前には死なない(状況起因処理は、能力の解決が終わってから)。
  - **同梱の処理**: 実装待ちの能力(Amass、Evoke など)は、新しい機能を同梱したリリースで起動すると、処理が自動で入って「未処理」から外れる(AI は使わない)。
  - **関数と名詞**: 繰り返し使われる動作は、エンジンが持つ関数(`drawCards` `discardCards` `dealDamage` `gainLife` `loseLife` `amass`)。AI は、カードの固有の能力を、関数を呼んで書くだけで、関数は作れない。飛行・想起のような、引用されるものは名詞。ルールブックは「名詞・関数・カード・未処理」の 4 タブで、見るのは、実装されているかどうか。共有の能力(名詞でないもの)は廃止し、起動時に、カード固有の能力に自動で展開される。
  - **想起**(Evoke): 想起コストで唱えると、出たあとに「生け贄にする」誘発が自動で積まれる。自身の出たときの能力が先に解決される(積む順は選べない)。
  - 古い書き方(v2)の記録も読める(同じ意味の v3 に変換される)。
  - 対応していない文は「未対応」として残り、ボットにも「⚠エンジンが実行できない部分」として伝わる。効果の部品が増えると、古い版で作った「一部未対応」(`status: partial`)の記録は「ルール化」で作り直される。
- 対戦を始めるとき、パワー・タフネスやキーワードが無い古いクリーチャーのノートは、自動で Scryfall から取り直す(取れなかったカードは名前を出す。`Cards/` のノートの `power:` / `toughness:` を手で書いてもよい)。`*` のパワー・タフネスは計算できないので、パワー0・タフネス1として扱う。
- クリーチャーのパワー・タフネスが無い古いカードのノートは、デッキ画面の「情報取得」で補う。

## フォーマットのルール

デッキのノートの `format:` で決まる(Standard / Pioneer / Modern / Legacy / Vintage / Pauper / Commander。作成時に選ぶ)。`format:` が無い・知らないデッキは「制限なし」(同名4枚とサイド15枚だけ)。

- **60枚のフォーマット**: 同名カードはメインとサイドの合計で4枚まで(基本土地と、枚数の例外が書かれたカードを除く)、サイドは15枚まで。Vintage の制限カードは、メインとサイドの合計で1枚まで。
- **Commander**: コマンダー欄(1体。伝説のクリーチャーか「コマンダーにできる」カード)、同名1種(基本土地と例外を除く)、コマンダーを含めて100枚。伝説のカードにホバーして👑で指定、もう一度押すと解除。色の同一性とパートナーは未対応。
- そのフォーマットで使えないカード(禁止など)は、一覧で薄くなり、追加できない。コマンダーがいるデッキは、Commander 以外のフォーマットでは使えない扱い。
- 取り込み(Import)には制限をかけない。
- カードの使えるフォーマットは、カードのノートの `legal:` と `restricted:` に記録される。取得前のカードは、コマンド「Update card legality」で手動更新する(Vintage のデッキに足すときは、そのカード1枚だけ自動で確認する)。

## ノートの形式

| 場所 | 内容 |
|---|---|
| `Cards/<カード名>.md` | カード名、マナコスト、タイプ、効果テキスト、画像、収録一覧(Printings の表)、`legal:` / `restricted:`。設定した言語の名前は `name_local:` |
| `Decks/<デッキ名>.md` | `## Main` / `## Side`(統率戦は `## Commander` / `## Main`)に、`4 [[Lightning Bolt]] (m11 149)` の形で1行ずつ。`format:` `favorite:` `thumbnail:` |
| `Collection/<セット>.md` | `3 [[Lightning Bolt]] (149) LP foil` の形で1行ずつ(セットはファイル名、括弧は番号、状態と foil は省略可) |

検索は `Cards/` の結果に、Scryfall の結果のうち `Cards/` に無いカードを足して出す(同じ検索語は画面を開いている間は覚えて、API を呼び直さない)。追加したカードはノート化される。

## コマンド

- Fetch card from Scryfall / Create deck / Import deck (Moxfield text)(`4 Lightning Bolt (M11) 149`、`SIDEBOARD:` 区切り。カードは版まで指定して取得)
- Open dashboard / Open collection / Open current deck in deck view
- Update collection prices / Update card legality (cards without it)

## 設定

- 価格の通貨
- 効果テキストの言語、カード(画像)の言語(新しく取得するカードから反映)
- カード一覧をサイドバーに出す / 一覧にイラストを出す / 新しいタブをダッシュボードにする

## ビルド

```bash
npm install
npm run build   # main.js が生成される
```

## リリース

`manifest.json` の version と同じタグでリリースを作り、`main.js`・`manifest.json`・`styles.css` を添付します。
