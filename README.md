# Magic the Obsidian

Obsidian を Magic: The Gathering のデッキ構築ツールにするプラグインです。カードは Scryfall から取得してノート(md)になります。

## できること

- コマンド「Open dashboard」(または左のリボンのアイコン)でホーム画面が開く。「コレクション」でコレクション画面、「デッキ」でデッキ一覧(All / お気に入り、検索、新規作成、Import)。一覧のカードにホバーすると、♡でお気に入り(`favorite: true`)、🖼でデッキ内のカードからサムネイル(`thumbnail:`)を選べる。
- コマンド「Fetch card from Scryfall」でカードを取得し、`Cards/` にノートを作る(カード名、マナコスト、タイプ、効果テキスト、画像、収録セットの一覧)。
- コマンド「Create deck」でデッキを作り、`Decks/` にノートを作る。専用のデッキ画面が開く。
  - 名前・効果テキスト・タイプ・色で絞り込み検索。`Cards/` に無ければ自動で Scryfall を検索し、追加したカードはノート化される。
  - メイン/サイドの枚数設定。タイプ別に重ねて表示。カードにホバーすると拡大画像と効果テキストが左に出る。
  - 🖼ボタンでイラスト(収録セット)を選べる。選んだ版は `4 [[Lightning Bolt]] (m11 149)` のようにデッキのノートに保存される。
- デッキ画面を開くと、右サイドバーのタブとしてカード一覧のアイコンが置かれる(サイドバーは勝手に開かない)。デッキ画面が全部閉じるとアイコンごと消え、一覧が見えていたならサイドバーも畳む。検索・フィルターが空のときは、いまデッキに入っているカード(枚数つき)を並べ、クリックで+1、Shift+クリックで−1(そのカードがいる欄の枚数が増減する)。検索・フィルターすると結果が出て、クリックで追加、Shift+クリックで1枚削除(デッキ内のカードも検索の対象)。一覧は「コスト・色の帯・名前」のリストで、イラストを薄く出せる(設定でオフ可)。ホバーするとデッキ画面の左に拡大画像と効果テキストが出る。設定の「カード一覧をサイドバーに出す」をオフにすると、画面内の検索欄に戻る。コレクション画面は自前の「Add cards」を使う。
- 検索は `Cards/` の結果に、Scryfall の結果のうち `Cards/` に無いカードを足して出す(同じ検索語は画面を開いている間は覚えて、API を呼び直さない)。
- コマンド「Import deck (Moxfield text)」で、Moxfield 形式のテキスト(`4 Lightning Bolt (M11) 149`、`SIDEBOARD:` 区切り)からデッキを一括作成。カードは版まで指定して取得し、`Cards/` に無いものだけノート化する。デッキ画面の「Import」ボタンからは、今のデッキにカードを足せる(枚数は加算)。
- 枚数制限はフォーマットごとのルール(デッキのノートの `format:`、無ければ構築戦)。構築戦は、同名カードがメインとサイドの合計で4枚まで(基本土地と、枚数の例外が書かれたカードを除く)、サイドは15枚まで。超える追加は断られる。取り込みには制限をかけない。
- デッキ一覧では、使えるフォーマット(デッキ内の全カードが使えるフォーマット。コマンダーがいるデッキは Commander のみ)で絞り込める。カードの使えるフォーマットはカードのノートの `legal:` に記録され、取得前のカードはコマンド「Update card legality」で手動更新する。
- デッキ作成時にフォーマット(Standard / Pioneer / Modern / Legacy / Vintage / Pauper / Commander)を選ぶ(`format:`)。そのフォーマットで使えないカードは一覧で薄くなり、追加できない。60枚のフォーマットは同名4枚(Vintage の制限カードはメインとサイドの合計で1枚。制限の情報が無い古いカードは、追加時にそのカード1枚だけ自動で確認する)・サイド15枚まで。統率戦はコマンダー欄(1体、伝説のクリーチャー)・同名1種・100枚。色の同一性とパートナーは未対応。
- 統率者構築では、伝説のカードにホバーすると👑でコマンダーに指定できる(1体まで、もう一度押すと解除)。コマンダーはメインの上に並ぶ。デッキ画面の見出しは、全フォーマット共通で「Commander / Planeswalker / Creature」「Sorcery / Instant」「Artifact / Enchantment」「Land」の列に並ぶ。
- デッキ画面のタブの右にフォーマットの選択があり、作成後に変えられる(統率戦とそれ以外のあいだは不可)。`format:` が無い旧版のデッキは「構築戦(制限なし・旧)」で、使用可否も制限カードも見ない。
- デッキのノートの末尾に「動き方」欄ができる(勝ち筋・序盤・中盤・注意点)。自由に書き換えてよく、デッキ画面の操作では消えない。
- デッキのノートはカードへのリンクになるので、グラフビューでカードの採用率が見える。
- コマンド「Open collection」で所持カードの画面が開く。「Add cards」で検索して追加。グリッド/リスト表示、セット・色・名前で絞り込み、版ごとの価格(USD)と合計が出る。価格は「価格を更新」ボタンかコマンド「Update collection prices」で手動更新(自動では取得しない)。
  - 行ごとに状態(NM/LP/MP/HP/DMG)と foil を記録。ホバーで1枚だけ変更できる。
  - `Collection/<セット>.md`(セットごとのノート)に `3 [[Lightning Bolt]] (149) LP foil` の形で保存される。
- 既存のデッキのノートを画面で開くには、コマンド「Open current deck in deck view」。
- 設定で、効果テキストの言語とカード(画像)の言語を選べる。設定は新しく取得するカードから反映される。

## BRAT でのインストール

1. Obsidian に BRAT プラグインを入れる。
2. BRAT の「Add Beta plugin」に `daredemonaimono/magictheobsidian` を入力する。
3. 設定の Community plugins で「Magic the Obsidian」を有効にする。

## ビルド

```bash
npm install
npm run build   # main.js が生成される
```

## リリース

`manifest.json` の version と同じタグでリリースを作り、`main.js`・`manifest.json`・`styles.css` を添付します。

## クレジット

カードデータと画像は [Scryfall](https://scryfall.com/) の API を使っています。Magic: The Gathering は Wizards of the Coast の商標です。このプラグインは非公式です。
